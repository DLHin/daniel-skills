# Daniel Skills

A collection of reusable agent skills and supporting resources.

## Available packages

| Package | Description | Installation |
| --- | --- | --- |
| [project-readme-keeper](project-readme-keeper/) | Project documentation and progress tracking rules for Codex and Cursor. | [Installation guide](project-readme-keeper/INSTALL.md) |

Packages are stored in their original directory structure. Follow each package's installation guide to use it in another project.

## Invoke project-readme-keeper

After installing the package's skill in your target project:

- **Cursor:** `/project-readme-keeper`.
- **Codex:** `$project-readme-keeper`, or select it with `/skills` in the CLI / IDE extension.
- **Codex CLI / IDE extension, optional legacy shortcut:** `/prompts:project-readme-keeper` after installing the bundled prompt. Custom prompts are deprecated; see the [installation guide](project-readme-keeper/INSTALL.md#invocation-and-slash-commands) for setup and limitations.
